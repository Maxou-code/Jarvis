# Contribuer a JARVIS

Les contributions externes sont acceptées uniquement sous forme de proposition
de modification au depot officiel.

## Methode

1. Creez une branche depuis la branche principale.
2. Limitez chaque pull request a un objectif precis.
3. Decrivez clairement le probleme, la modification et les tests effectues.
4. Ne joignez pas de secrets, donnees personnelles ou informations confidentielles.
5. Respectez les conventions existantes du projet.

## Droits sur les contributions

Une contribution reste une proposition jusqu'a sa validation. En soumettant une
pull request, vous autorisez son integration selon les termes de la
[Licence JARVIS - Source disponible](LICENSE).

Toute redistribution publique d'un fork, d'un paquet ou d'une modification
independante reste interdite sans autorisation ecrite.
